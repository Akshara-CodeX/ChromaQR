## 🌈 About The Project

**ChromaQR** is a web-based QR code generator designed to make sharing links more creative, personalized, and visually appealing.

Instead of generating traditional black-and-white QR codes, ChromaQR allows users to transform ordinary links into beautifully designed QR codes with customizable colors, themes, patterns, and images.

Whether you want to share your LinkedIn profile, personal portfolio, business website, or promotional link, ChromaQR makes the experience more engaging.

The idea behind this project was to combine **functionality, creativity, and personalization** into one interactive web application — without using any frontend frameworks.

## 🚀 Key Features

### 🔗 1. Instant QR Code Generation
- Generate QR codes simply by entering a URL.
- Automatically generate the QR code from the provided link.
- Preview the generated QR code instantly.

### 🎨 2. Multiple Creative Themes
- Explore multiple visually appealing QR code themes.
- Experiment with different colors, backgrounds, and patterns.
- Switch between themes to find your preferred design.
- Create QR codes that match your personal style or brand identity.

### 🖼️ 3. Image & Logo Integration
- Upload custom images to personalize your QR codes.
- Incorporate profile pictures or logos into QR code designs.
- Create QR codes with a more recognizable visual identity.

### ✨ 4. Advanced Customization
- Customize QR code colors and visual appearance.
- Experiment with different QR patterns and styles.
- Adjust design elements through interactive controls.
- View changes through the live preview.

### 💌 5. Greeting-Based Designs
- Explore greeting-inspired QR code themes.
- Display greetings based on the time of day.
- Make QR code designs more expressive and engaging.

### 👀 6. Live Preview
- See your QR code design while customizing it.
- Experiment with different styles before downloading.
- Get an immediate visual representation of your changes.

### 💾 7. Save & Download
- Save your customized QR code designs.
- Download generated QR codes for future use.
- Export designs in PNG and SVG formats.

## ⚙️ Getting Started

Want to explore or run ChromaQR locally?

Follow these simple steps.

### Prerequisites
- A modern web browser.
- A code editor such as Visual Studio Code.
- Git (optional).

### Installation

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd ChromaQR
```

**3. Open the project**

Open the project folder in Visual Studio Code.

**4. Run the application**

Open `index.html` in your browser or use the Live Server extension in VS Code.

That's it! You're ready to explore ChromaQR. 🚀
